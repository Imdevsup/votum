Votum uses GitHub to confirm you're a real developer. We read your public profile and your following list — nothing else, and nothing is stored until eligibility is confirmed.

What happens next?
  1. GitHub confirms your account and sends an authorisation back to Firebase.
  2. Firebase issues an ID token to this page.
  3. We forward both the ID token and your GitHub access token to the Votum backend.
  4. The backend runs the eligibility check, syncs your follow list once, then issues a session cookie.
  5. You can close this tab — the extension picks up the session automatically.
