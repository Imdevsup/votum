Sign in

Votum uses GitHub to confirm you're a real developer. We read your public profile and following list — nothing else, and only after you authorise.

What happens next?
  1. GitHub asks if you'll authorise the Votum OAuth App.
  2. If yes, GitHub redirects back to the Votum API with a one-time code.
  3. The API exchanges that code for an access token, looks up your profile, runs the eligibility check, and issues a session cookie.
  4. You land back here with a "Signed in" message. Close the tab — the extension picks up the session automatically.
